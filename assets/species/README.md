# 種の写真の差し替え方法

- ファイル名を `config/species.json` の `code` に合わせて置くだけで自動的に使われます。
  例：`amagaeru.jpg`, `ezoaka.png`, `ushigaeru.webp`
- 対応拡張子：`jpg` / `jpeg` / `png` / `webp`（同じ code で複数ある場合は jpg → jpeg → png → webp の順で最初に見つかったもの1つだけを使用）
- ファイルが無い種は、自動的に「種名を書いたグレーのプレースホルダ」で表示されます（`unknown` は「？」）。
- 画像を追加・変更したら `npm run build`（または `npm run dev`）を実行し直してください（ビルド時に存在チェックして埋め込みます）。
- 推奨：横長〜正方形、数百KB以下（表示は横88px程度のサムネイルなので大きすぎる画像は不要です）。

## 現在の写真について

現在は差し替え用の仮素材として、Wikimedia Commons の写真を使用しています。研究室が撮影した写真へ差し替える際は、`docs/CREDITS.md` の「種の写真」と `src/index.html` の「写真の出典」を、実際に使う写真に合わせて更新するか、不要になった Commons の記載を削除してください。

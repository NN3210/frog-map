# PRIVACY — プライバシー説明文

「カエル見つけたマップ」のプライバシーに関する説明文と、その実装上の根拠をまとめたものです。掲示物・配布物・Webページなど、来場者向けの文言を作るときはこのファイルの (a)(b) をそのまま使ってください。

---

## (a) アプリ内に表示している説明文（3行）

使い方モーダル（`src/index.html` の `#usage-modal` 内、`.privacy-note`）に表示している文言をそのまま転記したものです。文言を変更する場合は `src/index.html` を直接編集してください（本ファイルは転記のみで、表示の正ではありません）。

> このアプリは、あなたの端末の情報（位置情報・写真・連絡先など）を取得・保存しません。
> 投稿されるのは、地図でタップした場所と、フォームで選んだ内容だけです。
> 投稿された場所は、研究のために保存され、精度を粗くした上で地図に表示されることがあります。

---

## (b) 掲示物・配布物に載せる版（少し長い版）

QR掲示物や配布チラシなど、アプリ外の紙面に載せるための文言案です。**「サーバに一切の通信記録が残らない」とは書かず**、「取得・保存しない」と対象を明確にした表現にしています（Webサーバである以上、ホスティング事業者側のインフラログを完全にゼロにすることはできないため）。

> 「カエル見つけたマップ」について
>
> このアプリは、スマホの位置情報・カメラ・連絡先・Cookieなど、あなたの端末の情報を取得・保存しません。ログインやアカウント登録も不要です。
>
> 投稿していただくのは、地図でタップした場所と、フォームで選んでいただいた種類・時期・個体数などの内容だけです。名前・住所・電話番号などをこちらからお聞きすることはありません。
>
> いただいた投稿は、〇〇大学〇〇研究室が管理するデータとして保存し、カエルの生息状況を調べる研究に利用します。地図上に公開表示する場合は、場所の精度を粗くしたうえで表示します。
>
> ご不明な点は、ブース担当者までお気軽にお尋ねください。

※「〇〇大学〇〇研究室」の部分は、掲示・配布時に正式名称へ差し替えてください。大学のプライバシー方針ページのURLが決まっている場合は、`config/map.json` の `privacyPolicyUrl` に設定するとアプリ内のリンクとしても表示されます（未定の場合は空のままでリンク非表示）。

---

## (c) 実装上の根拠

上記(a)(b)の説明文が実際のコードでどう守られているかの一覧です。仕様変更でここが崩れていないか確認するときに使ってください。

- **Geolocation API を使用しない**：`navigator.geolocation` を呼び出すコードは無い。「現在地」ボタンも設置していない（要件3.1参照）。地図の中心・ピンは地図タップ操作のみで決まる。
- **Cookie を使用しない**：`document.cookie` を読み書きするコードは無い。
- **localStorage / sessionStorage を使用しない**：送信失敗時に入力内容を保持する仕組みは、ページを閉じると消える**メモリ上の変数**のみで実現しており、ブラウザストレージへの保存は行っていない。
- **アナリティクス・外部トラッカーを使用しない**：Google Analytics 等の計測タグは埋め込んでいない。
- **外部接続先は2つだけ**：地理院タイル（`https://cyberjapandata.gsi.go.jp/xyz/std/{z}/{x}/{y}.png` および航空写真 `https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg`、地図画像の取得のみ）と、GAS のウェブアプリURL（投稿の送信・公開ピンの取得）。地図ライブラリ（Leaflet）などのJS/CSSは外部CDNからではなく、`npm run build` で自前のバンドル（`dist/app.js` / `dist/app.css`）として配信する。
- **座標は保存時に4桁、公開表示時に3桁に丸める**：緯度経度は `config/map.json` の `roundDecimals`（既定4桁＝約10m精度）で保存し、`?action=pins` で公開する際はさらに `publicDecimals`（既定3桁＝約100m精度）に丸め直す。丸め処理はクライアント側と GAS 側の両方で行っており（`gas/Code.gs` の `roundTo`）、生の高精度座標がサーバに残らない。
- **IPアドレス・User-Agentを保存しない**：GAS の `doPost` / `doGet` は投稿本文（JSON）以外の値をスプレッドシートに書き込んでおらず、リクエスト元のIP・User-Agent・端末識別子を保存する処理自体が実装に存在しない。
- **氏名・連絡先の入力欄を設けていない**：投稿フォームに氏名・住所・電話番号を入力する項目は無い（自由記述「ひとこと」欄は既定で非表示 `enableComment:false`。有効化する場合も「個人が分かることは書かないでください」という注意書きを表示する）。
- **アカウント登録・ログイン機能を実装していない**：投稿に認証は不要で、識別子はサーバ側で発行する `record_id`（UUID）のみ。
